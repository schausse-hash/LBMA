💾 Backup des données v1

← Admin
Chaque bouton télécharge la table complète en CSV (UTF-8, ouvrable dans Excel). La pagination est automatique au-delà de 1000 lignes. Tout exporter regroupe toutes les tables dans un seul fichier ZIP daté (structure incluse). Exporter la structure (SQL) télécharge le squelette de la base (tables, index, vue, fonctions, sécurité) généré en direct — c'est ce qu'il faut, avec les CSV, pour tout rebâtir chez un autre fournisseur. La table admin_users est protégée par la sécurité Supabase : son export peut échouer avec la clé publique — c'est voulu (les mots de passe ne doivent pas circuler).
